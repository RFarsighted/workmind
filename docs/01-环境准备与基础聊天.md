# 01 环境准备与基础聊天

本文介绍 WorkMind 的本地环境准备、全栈启动、服务健康检查和基础聊天校验。适用于 Windows PowerShell。

## 准备环境

安装并启动 Docker Desktop（包含 Docker Compose）。Node.js、pnpm 和 uv 已在容器环境中提供，无需在本机单独安装。

## 配置密钥

在仓库根目录打开 PowerShell，首次运行时复制环境变量模板并填写 DeepSeek 密钥。需要测试知识库时，也填写 SiliconFlow 密钥：

```powershell
if (-not (Test-Path .\server\.env)) { Copy-Item .\server\.env.example .\server\.env }
notepad .\server\.env
```

```dotenv
DEEPSEEK_API_KEY=你的密钥
SILICONFLOW_API_KEY=你的硅基流动密钥
```

真实密钥只保存在本机的 `server/.env`，不要提交该文件。

## 启动服务

仍在仓库根目录运行：

```powershell
docker compose up -d --build
```

Compose 会启动 PostgreSQL、Chroma、FastAPI 和 Vue 前端；后端启动时会自动执行数据库迁移。首次启动需要下载镜像并构建。

- 前端：<http://localhost:5173>
- 后端健康检查：<http://localhost:3000/health/ready>

查看容器状态和后端日志：

```powershell
docker compose ps
docker compose logs -f server
```

就绪检查中 PostgreSQL 和 Chroma 应显示 `ok`。该检查不验证模型 API 密钥。

## 校验基础聊天

在前端聊天页面发送一句话，确认回答逐步显示并正常结束。也可以在 PowerShell 查看 SSE 响应：

```powershell
curl.exe -N -H "Content-Type: application/json" -d '{"message":"请用一句话介绍 WorkMind。","sessionId":"local-check","userId":"user-demo","role":"default"}' http://localhost:3000/api/chat/stream
```

成功响应包含 `start`、一个或多个 `token` 和 `done` 事件。聊天消息会保存到 PostgreSQL。

完整的服务启动、RAG、Agent、工作流、ERP、Prompt 调试和 Token 看板验收步骤见[本地运行与校验总览](local-run.md)。
